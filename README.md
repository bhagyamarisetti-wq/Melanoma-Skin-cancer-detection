# Melanoma Skin Cancer Detection

## Project Description
This project uses a Vision Transformer (ViT) model to detect melanoma skin cancer from dermoscopic images. The model was trained using a Kaggle dataset and developed in Google Colab.

## Technologies Used
- Python
- Vision Transformer (ViT)
- TensorFlow
- NumPy
- Pandas
- Matplotlib
- Google Colab

## Features
- Detects melanoma skin cancer from skin lesion images
- Deep learning-based image classification
- Supports early diagnosis using AI
