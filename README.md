# Melanoma Skin Cancer Detection using Vision Transformer (ViT)

## Overview
This project uses a Vision Transformer (ViT) model to detect melanoma skin cancer from dermoscopic images. The model was trained on a Kaggle dataset using Google Colab.

## Features
- Image classification using Vision Transformer (ViT)
- Skin lesion detection
- Deep learning-based prediction
- High classification accuracy

## Technologies Used
- Python
- TensorFlow
- Vision Transformer (ViT)
- NumPy
- Pandas
- Matplotlib
- Google Colab

## Dataset
- Kaggle Skin Cancer Dataset
